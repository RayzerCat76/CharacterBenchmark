# CharacterBench Alpha

This is an experimental evaluation build intended for testing and feedback.

- Scores are diagnostic signals, not scientific measurements or general model-quality rankings.
- The bundled fictional characters, settings, and benchmark prompts are original test material.
- Do not add or redistribute copyrighted character datasets, scripts, voices, art, or lore unless you have the rights to use them.
- CharacterBench itself sends no telemetry. Network requests occur only when you configure a model provider.
- This private alpha package is provided for evaluation; no redistribution rights are granted.
